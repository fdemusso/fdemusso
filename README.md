I like taking systems apart to understand how they actually work—from compiling typed schemas down to raw SQLite tables, to reverse-engineering legacy binary formats and running my own infrastructure at home.

Most of my time goes into building software that stays fast, predictable, and cheap to run:

- **Edge & Backend:** Designing zero-cost serverless systems on Cloudflare (`Workers`, `D1`, `R2`) and layered Python backends (`FastAPI`, `WebSockets`) with strict validation and deterministic behavior.
- **Applied AI & Simulations:** Building anomaly detection pipelines, real-time vector-search computer vision (`FAISS`, `ArcFace`), and multi-agent workflows where LLMs are called only when deterministic rules aren't enough.
- **Self-Hosting & Systems:** Running a Proxmox VE homelab with LXC containers, Docker Compose stacks, Tailscale mesh networking, and Cloudflare Tunnels—because owning your stack teaches you things cloud dashboards hide.
